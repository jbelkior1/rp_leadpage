# PS Videomaker — leadpage

Landing page de Pedro Santos, videomaker. Objetivo da página: orçamento pelo WhatsApp.

## Estrutura

```
index.html      a página inteira (markup + lógica + estilos inline)
support.js      runtime que renderiza a página
assets/         imagens
  pedro-hero-v3.png   recorte do hero (PNG com transparência)
.nojekyll       desliga o processamento Jekyll do GitHub Pages
```

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
A página fica em `https://jbelkior1.github.io/rp_leadpage/`.

## Seções

1. Hero com recorte e parallax no mouse
2. Números das redes sociais
3. Showreel em destaque (16:9)
4. Manifesto — o que é ser videomaker
5. Serviços (5 frentes)
6. Portfólio com abas por categoria
7. Processo em 4 passos
8. Logos de clientes
9. Depoimentos
10. Pacotes com preço
11. Sobre o Pedro
12. FAQ
13. Formulário de orçamento

## Pendências de conteúdo

Os trechos entre `[colchetes]` e os números `000` são placeholders:

- cidade, WhatsApp, @ do Instagram, e-mail
- números reais de visualizações, vídeos, seguidores e clientes
- links dos vídeos do portfólio e do showreel
- logos dos clientes e depoimentos reais
- valores dos pacotes e prazos do FAQ
